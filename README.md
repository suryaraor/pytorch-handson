## 🚀 Quick Start

1. **Clone this repository**
   ```bash
   git clone <your-repo-url>
   cd pytorch-handson
   ```

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Start with Chapter 1**
   ```bash
   cd 01_foundations/01_setup_and_basics
   python 01_installation_check.py
   ```

## 📋 Prerequisites

- Basic Python knowledge (variables, functions, classes)
- High school level mathematics (algebra, basic calculus helpful but not required)
- Enthusiasm to learn! 🎓

## 🎯 Learning Objectives

By the end of this course, you will be able to:
- ✅ Understand PyTorch fundamentals and tensor operations
- ✅ Build neural networks from scratch and with PyTorch modules
- ✅ Implement various deep learning architectures (CNNs, RNNs, Transformers)
- ✅ Create end-to-end machine learning projects
- ✅ Deploy models to production
- ✅ Optimize model performance and troubleshoot common issues
